# Glossary (seed — expanded in Phase 1)

- Purpose: shared hotel/ERP vocabulary. Audience: everyone. Last verified: 2026-10-01. Owner: project team.

| Term | Meaning (source) |
|---|---|
| Folio | Guest/member account collecting all charges of a stay for settlement (SOW ERP-07, §21) |
| Reservation / booking | Dated room hold with status lifecycle (SOW ERP-02) |
| Rate plan / seasonal pricing | Configurable room prices by category/season/promo (SOW ERP-02) |
| Room allocation / transfer | Assigning (or moving) a room to a checked-in guest (SOW ERP-03) |
| Housekeeping status | Room readiness state (cleaning → inspection → ready) visible to reception (SOW §19) |
| OTA / channel manager | External booking channels synced for inventory + reservations (SOW ERP-09) |
| RFID enrollment terminal | ESP32-based reception device mapping member ↔ card (SOW §20A: 1 terminal + 100 cards) |
| Tier / loyalty points | Membership levels and earn/redeem balances (SOW ERP-05) |
| Night audit | End-of-day reconciliation routine (standard hotel term; process defined in Phase 1/2) |
| RBAC | Role-based access control incl. view/create/edit/delete/approve/export/configure/report (SOW §22) |
| ADR | Architecture Decision Record (`02-architecture/adr/`) |
| Work unit | One phase (0–2, 5–9) or one module/sub-phase inside Phases 3–4 |
