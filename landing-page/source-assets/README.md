# Resort source assets

These files describe an unbuilt resort. All supplied visuals are **3D design concepts**, not photographs of an operating property.

## Organization

- `pdfs/`: byte-for-byte copies of the six supplied design PDFs, retaining their original filenames.
- `resort/scene-masters/`: native scene images extracted from those PDFs; these masters are not publicly served.
- Original files remain in `../ERP Resort/`, untouched.
- No ZIP files were present during setup.
- `SHA256SUMS.txt` records each PDF's SHA-256 hash. Copies and originals were verified to match during setup.

## Supplied PDFs

1. `3d Design - Bar Area.pdf`
2. `3d Design - Reception & Veg Resaturant.pdf`
3. `DESIGN 3D FOR ROOMS & COTTAGES.pdf`
4. `Design Concept 16-08Non Veg Restaurant.pdf`
5. `Design Concept Conference Hall.pdf`
6. `Golden Hills Resort 2.pdf`

This directory is outside `public/` and is not served by the application. Website-ready derivatives and their provenance manifest are in `../public/assets/resort/`.
